Guardar tu progreso en PDF

Crea un informe imprimible con tu perfil, resumen de kilómetros, historial de carreras y plan semanal. En la ventana de impresión, elige «Guardar como PDF».

Tus datos se guardan automáticamente en este navegador. El PDF es una copia legible; para proteger o transferir tus registros, conserva el navegador y el dispositivo donde se guardan.

Guardado en este dispositivo

Cada carrera, tu perfil y tu plan se guardan localmente en este navegador. No se envían a ningún servidor.

El respaldo PDF sirve para consultar, imprimir o compartir tu progreso. No se puede importar como datos editables; al cambiar de dispositivo, el navegador no transfiere automáticamente los registros.

Limpiar almacenamiento

Elimina perfil, entrenamientos y plan guardado de este navegador. Esta acción no se puede deshacer.

Privacidad y alcance

RUNNAPP funciona localmente y no realiza diagnósticos médicos. Las recomendaciones son sugerencias deportivas generales. Conserva una copia de respaldo si necesitas transferir los datos a otro dispositivo.
